# Carbon-Zero 完整终局实验

2026-11-24。实验从首轮冻结提交 `c73c283` 延续。[本轮研究交接](../carbon-zero-rl-followup-20261124.md)

## 协议

- 共同起点为 ft3 Apollo（风格索引 122），温度 0.4 和固定顺序解码。训练使用仓库参考裁判、合法的本方观察历史及冻结对手 ZW0。目标是正常终局胜负与有界分差各占一半的本地混合效用，提前淘汰使用裁判结果。
- C 每批两张地图，两席各成组，每组四局。同组四局分别用独立的 learner 和对手随机流，整批固定行为策略，所有已收集的回合都进入训练。组内效用减其余三局均值，无 value loss 和 GAE。采用按队伍回合的 clipped ratio、固定 299 步尺度和 0.1 的 reference KL；每批只遍历一次。
- A 从带校验值的原锚定 10k 权重、优化器、随机数流、未完对局状态恢复。A 和 C 的评测图、两席与对手流相同，训练地图来自各自固定协议；相同 E 是裁判推进预算，优化步数和训练地图不逐一对应。C 会走完整组再保存检查点，检查点的实际 E 可能高于目标。
- B1 先让完全冻结的双方打完，再用合法历史拟合 `U_T − Phi(s_t)`。前次 fit 为 7 批，复核扩为 14 批并换独立验证布局。用常数、原零初始化和仅看现金与轮次的拟合做比较，单独检查中盘。
- 新开发面板含 ZW0、ft3 generic、关闭搜索的 v6。每个对手独立四图换边，测试相同地图、同席、同对手流下相对于 ZW0 的配对分差与混合效用。A/A 固定 ZW0 与对手，只另抽 learner 流，用于观察环境噪声。地图是 bootstrap 的重采样单位，四图的区间只做探索性参考。

## 完整终局 critic 的校准

| 数据批 | 拟合 E | 留出 E | 价值头 / 现金基线 MSE | 中盘 MSE | 末盘 MSE |
| --- | ---: | ---: | ---: | ---: | ---: |
| 首批 | 32,676 | 9,568 | 0.346 / 0.300 | 0.340 / 0.298 | 0.248 / 0.135 |
| 扩展 | 65,869 | 18,841 | 0.291 / 0.241 | 0.274 / 0.205 | 0.219 / 0.123 |

扩展批的开局价值头优于现金基线，MSE 为 0.416 对 0.473。中盘和末盘误差更大，因此 B1 只完成 critic 训练与留出验证，未开启策略更新。两批验证布局不同，两行之间的 MSE 不能用于推断多一倍数据的净效果。

用扩展批拟合好的 value head，在相同 32 个真实终局标签上各做一次 value-only 步骤。只更新价值头时，worker 和 base logits 均逐项不变。允许 value 更新共享层后，原始 worker logits 最大变化 0.602，base 最大变化 0.745。这个对照证明梯度可以影响动作分布，解不开 PPO 首轮退化中各因素的相对贡献。[扩展批指标与配对诊断](critic-expanded/critic.json)

## RLOO 训练与校验

C 依次实际运行 14,057、51,874、103,801 E 后保存三个档。完整主跑 22 批、88 组、352 场，216 次优化步骤。采集 476 秒，优化 292 秒。最大批内近似 old KL 为 0.0212。完整指令和条件 mask 的 gzip 训练轨迹保存在本机，逐批 SHA-256 保留在更新记录里。

四项专项测试通过，包括可枚举双动作期望梯度、同分组零奖励梯度、完整组 RNG 重放和裁判真实提前淘汰。仓库既有 16 项测试通过。重放首批四局验证了实际指令、mask、old logprob 和裁判分数，50k 与 100k 纯策略导出各校验 64 个合法历史动作。[逐局轨迹校验](C/trace-audit.json)

## 决定与复现

完整终局 RLOO 是可以复跑的策略训练基线。首个种子下，C 在开发图对 ZW0 的效果和累计参考漂移都优于原锚定 PPO。两种子确认尚缺乏跨对手棋力增益，结果归档为研究候选。在证据不足的阶段缩短搜索转移评估，把主要算力用来验证纯策略。

B1 的扩展估值实验提供了一个具体切入点：保留公开现金和轮次作为显式基线，再用合法观察的网络特征拟合终局残差，先在独立地图上核对中盘与末盘误差。现有证据还无法比较完整终局 RLOO 和已校准的 PPO。

两种子 100k NumPy 导出均通过同样的 64 步动作一致性检查。实验权重、优化器、逐步训练轨迹和导出留在本机 `arena-runs/carbon-zero-terminal-20261124`，公开分支存放结果和校验值。[构件清单](artifacts.json) · [统计汇总](summary.json)
