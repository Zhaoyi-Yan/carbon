# B1 残差 critic：校准、策略训练与首个开发面板

2026-11-24。状态：**实验候选，未晋级**。基线仍为 `v11-yan-v8-elite-refit`，本分支不改变发布文件。
前置：[完整终局实验](../README.md) · [研究交接](../../carbon-zero-rl-followup-20261124.md)

## 1. 做了什么

- 在 `experiments/carbon_zero` 实现 **B1 残差 critic**：`V = w·pub + MLP(trunk, pub)`。`pub` 是 6 维合法公开特征（常数、`tanh(现金差/1500)`、轮次比例、两个交互项、`sign(现金差)×轮次`）。`w` 由训练集最小二乘闭式解固定，作为不可低于的现金基线；MLP 只学残差。
- 实现 **B2** `detach_value_trunk` 开关：value 分支对 trunk 做 stop-gradient，用于隔离“value 梯度改共享表示”这一条路径。
- 验收门槛（沿用交接文档）：留出集 **全盘、中盘、末盘 MSE 都严格优于常数与现金基线**；不通过则不开 actor 更新。
- 修复评估链路：`actor_from_checkpoint()` 从 checkpoint 读取 `residual_critic` / `detach_value_trunk` 再构造 Actor；`terminal_eval.py`、`terminal_drift.py` 改用该入口。没有这处修复，B1 checkpoint 无法评估。
- `terminal_critic.py` 额外保存 `heldout.npz`（标签、各模型预测、轮次、游戏分组），用于按游戏做 bootstrap。

14+4 批的分阶段解释方差：全盘 0.217 / 0.162，开局 0.118 / 0.010，中盘 0.222 / 0.181，末盘 0.408 / 0.404（残差 / 现金）。

按 64 场留出对局做 bootstrap（2000 次，地图为重采样单位），MSE 改善（现金 − 残差）：

| 阶段 | ΔMSE | 95% 区间 |
| --- | ---: | --- |
| 全盘 | +0.0143 | +0.0038 .. +0.0245 |
| 开局 | +0.0444 | +0.0054 .. +0.0835 |
| 中盘 | +0.0089 | +0.0005 .. +0.0174 |
| 末盘 | +0.0010 | −0.0083 .. +0.0101 |

结论：网络特征确实提供了超出“现金差 + 轮次”的信息，集中在中前盘；末盘与现金基线打平（点估计略好，区间跨零）。留出集预测整体偏高约 +0.08，与拟合/留出地图集的结果分布差异一致；GAE 用的是价值差，常数偏移大部分抵消，仍应在下一轮扩大留出图集确认。
另：`head_vs_trunk` 显示，价值头训练后若允许经共享 trunk，单次 value-only 步骤会让 actor logits 最大变化 0.47 / 0.69（worker/base）；`detach` 后严格为 0。

## 5. 解释与边界

- **B1 是目前唯一没有低于 ZW0 的臂**：两个检查点在三个对手上的配对变化都跨零并略偏正；A10/A50/C50/C100 在同一面板上都低于 ZW0（A50 对 ZW0 的区间不含零）。可支持的结论是“校准 critic 阻止了训练退化”，**不是“棋力提升”**。
- 同预算 10k 时 B1 明显优于 A（对两个外部对手区间不含零）；50k 时变成混合：B1 对 ZW0/v6 更好，A50 对 generic 更好。样本和地图都不足以判定 50k 的强弱。
- C100 在这块新面板低于 ZW0，与其 8 图确认面板的 −158 一致；开发图上的 +465 没有复现。RLOO 的“有效”仍然只在开发图上。
- 只有 12 张图、每格 24 局，区间很宽，且是多候选对比，不能当成定论。面板在 B1 训练前以固定 panel id 生成，未参与任何选型；但它在 critic 校准之后才确定，报告中按“新开发面板”而非“冻结测试集”看待。
- 训练局数的 W–L 只说明对冻结 ZW0 的拟合，不是泛化指标；A/C 的训练局数同样接近 50%，却在评估图上退化。

## 6. 下一步（未执行）

1. **确认**：25–40 张新图 + 第二训练种子（`--seed 24010000`）跑 B1-50k；这是“B1 是否真的不退化”的关键。
2. **转增益**：B1-100k，同时单变量降低 anchor 权重（0.1 → 0.05）或在 10k 后放宽 lr，检验“不退化”能否变成“超过 ZW0”。
3. **导出 gate**：残差模型的动作头不依赖 value，但 `terminal_export.py` / `checkpoints.py` 仍是按非残差前向写的；提交前必须验证导出文件在无 `pub` 输入时也能出动作，且 ≤10 MB、单步 ≤1 s。
4. 不建议现在晋级或上传；保持 v8 发布不变。
