# B1 残差 critic：校准、策略训练与首个开发面板

2026-11-24。状态：**实验候选，未晋级**。基线仍为 `v11-yan-v8-elite-refit`，本分支不改变发布文件。
前置：[完整终局实验](../README.md) · [研究交接](../../carbon-zero-rl-followup-20261124.md)

## 1. 做了什么

- 在 `experiments/carbon_zero` 实现 **B1 残差 critic**：`V = w·pub + MLP(trunk, pub)`。`pub` 是 6 维合法公开特征（常数、`tanh(现金差/1500)`、轮次比例、两个交互项、`sign(现金差)×轮次`）。`w` 由训练集最小二乘闭式解固定，作为不可低于的现金基线；MLP 只学残差。
- 实现 **B2** `detach_value_trunk` 开关：value 分支对 trunk 做 stop-gradient，用于隔离“value 梯度改共享表示”这一条路径。
- 验收门槛（沿用交接文档）：留出集 **全盘、中盘、末盘 MSE 都严格优于常数与现金基线**；不通过则不开 actor 更新。
- 修复评估链路：`actor_from_checkpoint()` 从 checkpoint 读取 `residual_critic` / `detach_value_trunk` 再构造 Actor；`terminal_eval.py`、`terminal_drift.py` 改用该入口。没有这处修复，B1 checkpoint 无法评估。
- `terminal_critic.py` 额外保存 `heldout.npz`（标签、各模型预测、轮次、游戏分组），用于按游戏做 bootstrap。

## 5. 解释与边界

- **按 U 看，B1 有值得继续检验的积极信号，但尚未证明超过 ZW0，也尚未证明不退化**：B1-50k 对 ZW0 ΔU +0.185 [−0.217,+0.558]，对 generic −0.086 [−0.488,+0.305]，对 v6 +0.045 [−0.142,+0.261]；相对 A50 对 ZW0 **+0.443 [+0.027,+0.817]**，对 generic/v6 为 −0.188/−0.074。区间跨零不能当作“已经打平”；声称非劣需要预先设定容忍度 ε 并检验 ΔU 下界。
- 同预算 10k 时 B1 的 ΔU 均高于 A10（对 v6 区间不含零）；50k 时混合：B1 对 ZW0 更好，A50 对 generic/v6 的点估计更好。样本和地图都不足以判定 50k 的强弱。
- 初始版本的“只有 B1 保住了棋力”来自原始分差表；按 U 重算后，A50/C50/C100 对 v6 的 ΔU 也为正，不能推出“其余 A/C 都退化”。
- C100 在这块新面板低于 ZW0，与其 8 图确认面板的 −158 一致；开发图上的 +465 没有复现。RLOO 的“有效”仍然只在开发图上。
- 只有 12 张图、每格 24 局，区间很宽，且是多候选对比，不能当成定论。面板在 B1 训练前以固定 panel id 生成，未参与任何选型；但它在 critic 校准之后才确定，报告中按“新开发面板”而非“冻结测试集”看待。
- 训练局数的 W–L 只说明对冻结 ZW0 的拟合，不是泛化指标；A/C 的训练局数同样接近 50%，却在评估图上退化。

## 10. P1 持续校准审计（8 图 × 2 席）

每个 checkpoint 作为 learner，对冻结 ZW0 打 8 张图换边（16 局）；逐步记录合法观测特征、公开现金差、轮次和最终 U，标签 `U−Φ`；现金比较器沿用预训练 B1 的系数，不在这 8 张图上重拟合。评估的是各 checkpoint **自带的** critic。GAE 用 λ=.95、整局、终局不 bootstrap；MC 优势为 `U−Φ−V`。

| checkpoint | 全盘 EV 值/现金 | 中盘 EV | 末盘 EV | GAE vs MC：mean\|Δ\| / corr |
| --- | --- | --- | --- | --- |
| ZW0（零价值头） | 0.000 / 0.179 | 0.000 / 0.172 | 0.000 / 0.532 | 0.491 / 无定义 |
| B1-10k | **0.261 / 0.177** | **0.253 / 0.214** | **0.341 / 0.320** | 0.356 / 0.504 |
| B1-50k | +0.042 / +0.027 | −0.017 / −0.030 | +0.323 / +0.290 | 0.426 / 0.425 |
| A10 | +0.001 / +0.078 | +0.001 / +0.042 | 0.000 / 0.398 | 0.467 / 无定义 |
| A50 | +0.001 / +0.247 | 0.000 / +0.290 | 0.000 / 0.554 | 0.478 / 无定义 |

读法（8 图探索性，不能当正式区间）：

1. **A10/A50 的 PPO 价值头在自己的策略上几乎没有排序能力**（EV≈0.001，预测接近常数），比同局的现金基线差一个量级。这和“冷 critic → 近常数 V → GAE 退化为 shaping 累加 → 短视野”一致，也说明“value 梯度小”不能推出“critic 不是问题”：它可能只是一个学不到东西的 critic。
2. **B1-10k 的 critic 在自己的策略上仍优于现金基线**（全盘 0.261 vs 0.177，中盘 0.253 vs 0.214，末盘 0.341 vs 0.320）。
3. **B1-50k 的 critic 明显向现金基线退化**（全盘 0.042 vs 0.027，中盘 −0.017 vs −0.030），超额信息基本消失。复审提出的“critic 可能只在起点可靠”在 50k 上有直接支持。
4. 所有臂的 GAE 与 MC 优势差距都很大（mean|Δ| 0.36–0.48，相关 ≤0.50；A 的近常数 V 使 corr 无定义）。这既解释了为什么继续压 TD loss 不等于 V 变好，也为 P3 的“完整终局回报 + 冻结状态基线”提供动机。
