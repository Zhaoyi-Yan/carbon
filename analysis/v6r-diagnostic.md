## 重算

逐步经济记录读取原版裁判实际修改现金和载碳的位置，对每步双方核对现金收支、载碳收支和存档现金，再核对终局余额及奖励。每 75 步汇总一次，末段为第 226–299 步。历史原始评测行及本轮评测行以各自字段完整保存在 JSON 内。

从仓库顶层执行以下命令，可在原版裁判中重放此次四局。该命令只读已归档的动作，不运行策略网络。

```sh
python experiments/v6r/trace_economy.py --raw-dir analysis/v6r-diagnostic-actions --ledger-dir /tmp/carbon-v6-ledgers --summary /tmp/carbon-v6-economy.json
```

如需再生成新对局，以下命令从固定 Git 版本读取并核验两份策略。输出目录需为这轮实验新建。可用 `--jobs 1` 控制并发或 `--seeds 171684640` 选一张地图。

```sh
CARBON_DEBUG=1 python experiments/v6r/trace_games.py --raw-dir /tmp/carbon-v6-fresh
```
