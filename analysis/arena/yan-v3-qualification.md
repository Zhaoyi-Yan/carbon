# yan-v3 晋级评测

对手是线上 yan-v2，已核对策略文件 SHA-256 为 `0483eca2a5e8031270dfb89b87cd5d901ee81f823383f6094f8ed839dec6a7dd`。每批均用四张新地图各交换一次出生位，默认赛事步数，按最终现金评分。本次上线试验的条件在首局结算前确定：八局均正常结束，总胜场至少五场，每个出生位至少两胜，八局平均现金分差为正。此前的开发、筛选和历次复测另外保留。八局用于决定是否值得试投，线上强度仍看后续定位。

第一批测试冻结的[护树候选](https://github.com/Zhaoyi-Yan/carbon/blob/9e99a57fb2d16783c53ab351c197f82b877877ff/submission.py)。种子依次是 764880429、896044050、754651160、588107555。训练与回放资料中的已知种子均不包含这四张图。

第二个候选沿用护树搜索，对模拟棋盘中的行动采样做批处理。[完整加速版](https://github.com/Zhaoyi-Yan/carbon/blob/791c2f23f7dfa46228f6578a5df8e3391a334a7a/submission.py)。若第一批未通过，可在另一批冻结种子 839712143、80450718、802954434、533778689 上以相同条件测试加速版。每个候选只计算自己事先选定的这一批。种子来自 ASCII 字符串 `yan-v3-frozen-eval-{i}` 和 `yan-v3-batched-holdout-{i}` 的 SHA-256，取前四字节大端整数模十亿，i 取 0 至 3。

环境为 Apple M4、Python 3.12.16、NumPy 1.26.4、PyTorch 2.5.1 CPU，四局并行。每局的代码和地图指纹、实际搜索次数、耗时、比分记录在 JSONL。
