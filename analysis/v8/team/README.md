旧版三张 0 号位败图中，双方首笔交货同在第 6、7 或 9 步发生。第 75 步这三图双方的两个基地都有过入库。开局分工版在新图第 125 步平均少收约 160 碳，终局均分领先，尚不能把终局改善归因于前期周转。

末段版从第 190 步开始比较备选动作。初筛到该步已领先约 249，之后分差平均缩小约 206。复核到该步落后约 436，后段追回约 91。分叉前局面和限时搜索的波动均会影响终局，本次数据未证明该修改稳定强于 v7。

全部败局、地图、出生位、文件哈希、耗时、各阶段收支和逐步动作随报告保存。复现单文件时在仓库根目录运行 `python3 experiments/v8/teamplay.py opening candidate.py`，可将 opening 换成 convoy、intercept、closing 或 combined。
