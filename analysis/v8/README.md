第二批树收益模型用 16 份公开回放中实际买入或夺取的树拟合，以持续持有期间的收入为标签。另外八张公开地图仅用于检查预测误差。新种、夺树的平均绝对误差分别为 24.25 和 10.83，训练集中位数预测分别为 35.25 和 22.63。这项检验覆盖了实际发生的购买，无法从中判断所有放弃购买的收益或改变整队行动后的胜率。

树净收益含树吸收收入及树格碰撞入账，并扣除种植和夺树成本。基地入账含自己送回及碰撞结算。每一局都从种子和双方记录的动作重播，逐步核对双方现金与终局分数。原始动作及耗时保存在本目录两份 games.jsonl.gz 中。候选重新构建的哈希见两份 protocol.json。
