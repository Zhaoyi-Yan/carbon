# yan-v8 运碳实验：多采一步与下一趟交货

本地使用冻结 v7 标签 `v10-yan-v7-selfplay-prior`。候选只为一个采碳员提出停留或向基地走一步的备选动作，保留 v7 的种树逻辑、权重和原始行动方案。候选从第 45 步开始可以提出选项。

通过每个工人的实际交货记录估计后续循环的时间与收入。历史先验取自上一轮 16 场中 v7 一侧的 1,202 次已完成周转，分为五档。实战中用本局同一起点基地的近期交货更新估计。另按附近可采地块，逐一比较出发、采 1 至 5 步、返库的可行性。两种选择都要求已载的货能入库。终局前时间不足以再跑一趟时，该趟收入记为零。上一趟多采过的碳会从该地块的下一趟估值扣除。周转先验只统计完成的运输，未来税收、敌人和货源变化会使估值偏离实盘。
