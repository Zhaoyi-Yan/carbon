# 用轻载采集员封住对手入库前一格

在独立的两张地图、8组配对分支上，启用封路后，对手26步内平均多入库18.69，低于招工价的回合数平均少0.38。我方现金差平均增加46.73，病例中位数为0。封路偶尔能明显奏效，但这次验证没有复现对对方流动性的稳定压制。原冻结策略保持独立。

**触发条件。** 我方至少4工、现金至少90；对手现金低于45、公开树收入每步低于10，距其最近基地2至8格的高载采集员合计至少90碳；我方至少有一名载货不超过13.5的采集员位于敌基地3格内。比较这辆车继续执行原安排或移至一处基地入口，对敌方到两个基地未来八步的最佳折现到款估计有多大影响，并扣掉离开原采矿点的成本。每步最多修改一名工人。允许目标工人在自己的基地碰撞交货，因此只控制入库前的格子；改动作时避开敌基地、友军落点和能撞赢守卫的轻车。估计中的守卫位置在未来几步保持不动，活对手可以绕行或反击。

每组均从同一正式裁判快照开始，前缀逐帧校验。封锁方使用冻结 QQ-v6 的根部策略，省去前瞻搜索和二次选择。对方分别使用随局面反应的 Artemis 近似和按回合固定随机种子的 Apollo 近似。分叉后每步双方都重新决策，未提供未来实局命令。每组只衡量26步，所有数字均按一对「启用封路、维持原策略」做差，不能作为整局胜负或联赛胜率。独立组取既有破产败局，各选最早满足公开资格的两个起点并隔开40步，地图属于定向压力测试样本。

原截图图的第90步分支对 Artemis 近似能少让对手入库229.75，对手缺钱多19步，我方现金差增加219.90。第164步对同一近似，对手到款下降297.92，但我方也少到账499.86，现金差恶化650.94。独立图 `f5e69…` 第92步对两种替身反而分别多让对手入库369.67、498.10，后者使现金差恶化393.33。根部模型会高估静态占位的封锁价值，后续自己的运送和换防也会改变；单独按拒绝对手入库的分数执行，尚不宜升为主策略。
