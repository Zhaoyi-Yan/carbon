# 能预测载货车回款，为什么直接改第一步反而少收钱

**保留预测模型作研究，本轮冻结策略继续使用原来的动作。** 在 36 张留出地图上，知道载货车的实际第一步能降低 10、20 步累计入库金额的预测误差。但在两张完全排除的旧地图上，按预测改动一辆车的第一步，16 对闭环分叉的全队净入库在 10 步时平均多 33.68，在 20 步时平均少 51.76。截图败局图的 20 步净入库减少，旧胜局图则小幅增加。

## 回放中的实际第一步

每个样本对应当前持货至少 60 的一名采集员。读取本席位当前资源视野、双方公开工人和基地、队内持货占比和敌我单位密度，计算候选落点距己方两个基地的距离变化、可见矿量、附近敌方轻车和友方拥堵。对每个候选用同一组浅层树评估未来 10、20 步该 UID 向己方基地交回的毛额，包含继续采矿后回库和重复交货。死亡的工人后续自然记零。动作来自下一帧的已执行命令，预测器只读当前局面和候选第一步。上一轮工人位置仅用于候选的保护规则，跳过已经连续回家的工人。未来信息只进入标签；初始全图资源仅用于按地形去重。另拟合一个同容量模型，输入仅为选择走法前的工人和局面特征。

128 张训练图有 45,387 个载货决策，36 张整图留出有 14,171 个。初始资源和双方基地在八种旋转、镜像及交换席位下等价时视作同图。两张闭环评测图和此前第 190 步目标图均排除。每隔 4 步取样，同一图的决策存在相关性。

| 留出子集 | 工人决策数 | 10 步 MAE，忽略第一步 → 给定第一步 | 20 步 MAE，忽略第一步 → 给定第一步 |
|---|---:|---:|---:|
| 全部 | 14,171 | 54.18 → 48.09 | 72.76 → 71.61 |
| 下一步不直接进己方基地 | 13,305 | 56.86 → 50.41 | 75.62 → 74.37 |
| 持货 ≥120，敌方较轻或同载车辆在两格内 | 2,677 | 79.26 → 69.63 | 84.21 → 83.30 |
| 下一步远离最近己方基地 | 2,103 | 67.46 → 43.13 | 94.49 → 94.80 |

另做较强对照，给同容量的动作无关模型五种落点的全部特征摘要，仅隐去实际走了哪一步。其 10、20 步 MAE 为 52.66、72.13；给定实际动作仍为 48.09、71.61。将同一预测器对五个走法的预测均匀平均，误差则为 57.47、74.12。

每图等权，MAE 改善分别为 5.92、1.07。对 36 图有放回抽样的 95% 区间分别为 5.33–6.58、0.70–1.48。在回放中，走某个方向的工人往往还有后续采矿、回家或避敌的意图，事实预测只能学习到二者的关联。

## 真正改一步后发生了什么

QQ 在座 1，以冻结 Harbormaster 的实际落子为对照。对手是座 0 的主动 Master7sE 行为克隆。两臂从同一公开局面和历史复原，共用逐步随机数。实验臂只替换第一步的一辆车；随后两队都按自己的新局面重新行动。每张图用 31051、49069 两颗预定种子，在五个预定时段查找第一个满足支持度和预估收益条件的动作。40 次选点检查产生 16 对干预，不能视作 16 张独立地图。

禁止改动原先已锁定的回库、正在执行的回库路径和原走法已能拦截的高货值敌车；排除友方预定落点、新招工落点、敌方基地，以及允许敌方轻车下一步直接相撞的落点。每个动作类别在相近距离、载重和风险分组中需要有足够实际样本。两个期限的预计回款增量各权重一半。

| 真实分叉中的平均改变量 | 10 步 | 20 步 |
|---|---:|---:|
| 模型预计被改工人多交 | +35.70 | +23.92 |
| 该工人实际多交 | +43.10 | −16.96 |
| 己方全队入库 | +39.77 | −39.25 |
| 对方全队入库 | +6.09 | +12.51 |
| 己方减对方的净入库 | +33.68 | −51.76 |
| 局面现金分差 | +45.91 | −34.65 |

截图败局 `4063a34afedb6d4767a9118e1dee9e5d/1`（地图种子 1331727176）的八对分叉中，10 / 20 步净入库平均改变 −39.77 / −127.94。旧胜局 `cf276b32e4fd38f43497e60f271a3854/1`（地图种子 397168106）的八对则为 +107.12 / +24.42。20 步全队自身入库的 16 次比较中，4 次增加、1 次持平、11 次下降。有效干预覆盖原地采矿、向基地移动与改变行进方向。

具体到第 164 步，采集员 4 持货 297.92。种子 49069 下，模型把原走法向下的 20 步回款估为 50.43，改向上估为 88.49；原走法让该车交回 241.32，改向上却一笔都没交。模型能识别回放中哪类动作常伴随入库，但在这个局面，它漏掉了原走法给同一辆车保留的返程机会。

## 复现

模型为两组深度至多 4 的浅树，共约 35 KB，部署侧用 NumPy 推理。JSON 中保留所有训练与留出图的指纹、每图误差、所有干预 UID、双方逐笔入库、命令摘要及分叉现金。实验模块含独立的根搜索候选生成器，已冻结策略和装配入口沿用现状。

```sh
nice -n 19 python experiments/v7/carrier_action_fit.py --manifest ../v7-data/receipts-cache/index.json --cache ../v7-data/carrier-action-cache
nice -n 19 python experiments/v7/carrier_action_controls.py --manifest ../v7-data/receipts-cache/index.json --cache ../v7-data/carrier-action-cache
nice -n 19 python experiments/v7/carrier_action_branch.py --progress ../v7-data/carrier-action-branches.jsonl
nice -n 19 python experiments/v7/carrier_action_smoke.py
```
