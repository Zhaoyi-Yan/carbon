# Master 运输与拦截专家

从分配给 Master7sE、7sD 和 7sB2 的 42 张训练图提取 7,373 个局面。每个样本只取当事方可见的碳、公开的工人和基地，以及最多三步已发生的移动。冻结 Harbormaster 的 96 通道主干（风格 22）和原动作头。在每个格子的隐藏向量、54 张棋盘平面和 30 张历史动作平面上新增 24 通道的环形卷积残差；两个空间卷积分别看一格和两格之外的邻域。训练目标包括下一步工人行动、基地招募、三步后的位移。训练集内六张地图确定四个训练轮次，然后在全部 42 图重训；用剩下的 13 张完整地图评估。生成的专家权重占 37,210 字节。

## 候选及对接

生成器的默认调用 `master_spatial.build(code)` 仅嵌入模型和推理函数。在相匹配的 Harbormaster 主干上调用 `_mx_heads(obs,x,past,style='E')` 返回全部工人和基地 logits。输入应使用相应一方的合法资源观测，`past` 是最近三次公开玩家状态，最近的放在前面。若现有四个旋转的自方隐藏向量都源自风格 22，可传 `latent` 省去额外主干推理。已有的普通 21/22 权重和原行动逻辑继续独立工作。

`build(code,mode='tactical')` 在普通搜索候选全部生成后，尝试追加一个工人联动；保留原根、全部原搜索候选、所有基地指令及已锁定工人。符合条件的工人为己方近库重车，或已经靠近敌库的轻车，或与敌方近库重车相距至多三格的轻车。用公开局面判断，资金和双方总人数均不构成门槛。每个替代目的地均检查原有己方工人和新招单位的占位。搜索规划宽度至少三且生成阶段开始时仍在 550 毫秒以内才启用。

`build(code,mode='tactical-secondary')` 另允许一个有歧义的工人改走次选。专家首选必须与原根一致，第二高概率须至少 18%，且至少为首选的 45%；按两者之比排序，跳过会碰撞、受保护或已存在的联合指令。在 13 张留图中，以冻结根和专家一致的首选为条件，273 个有歧义的样本里，原根已命中 150 个。用空间专家次选能再覆盖 87 个，冻结根次选为 81 个，旧 Master 专家次选为 90 个。此项比较使用同一批单工人的真实示范，空间专家相对旧专家没有清晰优势。

已集成的可调用函数为 `_mx_tactical(obs,root,fixed,context,style='E',roles=None,ambiguous=False,existing=())`。外部调用者可传入自己筛选的 `roles`、锁定集合 `fixed` 与已有联合动作签名 `existing`。`context=(x,past,latent)` 在每次根推理结束后可从 `_ST['v5_history']['mx_context']` 取得。返回一个完整替代指令或 `None`。纯库模式可由调用方自行创建相同格式的上下文。根据 Master 示范学习到的动作准确率只衡量模仿，胜负需要另行配对对战。

## 第 190 步与逐局耗时

目标为 QQ 对 Artemis 的公开局 03100a95e8647c51a4d642fe08d856dd，QQ 执先，回放实际种子 205864169。以真实历史指令重放资源视野到第 190 步，当时两边均有十名工人，QQ 现金 3769.49。29 和 41 号采集员符合敌库附近轻车条件。空间专家的最优选择均与原根相同。允许有把握的次选后，41 号可以从 LEFT 改为原地，但宽度六的原候选集合已经包括这组行动。按原预算另跑时，计入根推理已用的 52.93 毫秒，两边均生成 23 组原候选，仍无独有行动，最终搜索指令一致。此局没有证据支持用空间专家改写第 190 步。

独立取十张旧实盘图，每图按预定步次取一个局面（第 52、73、88、109、124、142、158、173、194、215 步，八图已在额外预测验证使用，另外两图另选）。十个局面均不满足旧的弱势贫资门槛，八个能够复用风格 22 的主干隐藏态。原搜索固定宽度六、深度二，按图轮换两种测量顺序，在同一局面比较完全相同的原候选。只取最佳的空间专家在两张图追加独有联合，允许次选时为三张，在这十图均未成为最终搜索选择。

| 集成模式 | 生成耗时中位数 | 生成耗时 P95 | 完整搜索配对增量中位数 | 完整搜索配对增量 P95 |
| --- | ---: | ---: | ---: | ---: |
| 只取最优 | 2.12 ms | 9.05 ms | +8.88 ms | +51.52 ms |
| 允许一个次选 | 1.81 ms | 10.58 ms | +18.86 ms | +80.03 ms |

耗时取自同机单线程低优先级，额外候选需要模拟，整段搜索的差值还受并行评测负载波动影响。模式的绝对耗时差在小样本下不宜解读。根节点最后的可选修正与完整对局胜负不在这项测试内。

## 复现

从 `experiments/v7` 导入 `master_spatial` 即可使用 `build`。命令行读取冻结父文件并新建独立游戏文件：

```sh
python experiments/v7/master_spatial.py experiments/v7/checkpoints/harbormaster.py /tmp/master-spatial-agent.py --mode tactical
```

训练顺序为 `master_spatial_data.py DATA`、`master_spatial_fit.py DATA OUTPUT --reference FP32_OUTPUT`；预测验证用 `master_spatial_check.py DATA OUTPUT`、`master_spatial_external.py DATA OUTPUT`；打包精度用 `master_spatial_quant.py DATA FP32_OUTPUT OUTPUT`。在同一工作树运行 `master_spatial_tactical.py DATA TARGET_REPLAY`，添加 `--mode tactical-secondary` 可测试次选，`--production-target` 使用暖身后的原搜索计划单独核查第 190 步。

把允许一次选的空间工人方案装进 Harbormaster，在四张开发图与冻结 v6 换边。双方都运行宽四、深二、一个对手应手和三步延伸的完整对局。新版本为 4 胜 4 负，原 Harbormaster 为 3 胜 5 负，改动让两场原有败局转胜、一场胜局转败，平均分差由 +131.93 降至 −58.06。八局中的单局配对差从 −1542.45 到 +888.24。这里有动作预测的改善，整局收益仍不一致。[相同种子、座位与逐局配对](spatial-development.json)
