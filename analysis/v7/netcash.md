# 十步入库能否预示二十至三十五步后的净现金

从冻结入库模型的862张公开地图中选取450张，共30,065个局面。290图拟合，56图选择正则及相邻状态损失权重。104张最终留图同时避开冻结入库模型训练图及此前经济预测和资产模型的217张开发图。排除QQ–Artemis案例、QQ–Master7sE封锁与胜局对照，以及本轮开发和后续比赛的预定种子。所有输入来自当时公开的双方经济信息。地图、文件、种子与切分记在 `netcash-validation.json`。

目标是未来第20、35步双方实际现金分差减去当前现金分差，包含树收入、种树、抢树、招聘、碰撞与入库。只计入存在完整35步后续的局面。模型从两方的5步和10步入库估计、载货、采集员、种树员、剩余树龄及产量、现金余额、旧冻结经济预测和冻结的简化资产价估算增量。资产价使用现有载货风险、树价及人员替换价值，候选策略特有的幼树估值与货运修正另行保留。预测对两席反对称。

| 104张留图，6,938个局面 | 20步误差 | 35步误差 | 20步相邻增量排序 | 35步相邻增量排序 |
| --- | ---: | ---: | ---: | ---: |
| 现金加10步预计入库差 | 255.70 | 376.81 | 65.36% | 65.53% |
| 当前载货按基地距离折现 | 258.29 | 378.45 | 66.49% | 66.57% |
| 原简化资产估值 | 228.08 | 334.50 | 68.35% | 67.93% |
| 冻结经济预测，35步以20与50步头均值近似 | 212.86 | 278.55 | 67.83% | 65.85% |
| 包含资产价与收款的校准模型 | 208.64 | 275.17 | 67.57% | 65.33% |
| 实际插件的限幅混合，以原简化资产为基准 | 212.93 | 312.34 | 68.22% | 67.74% |

误差为现金单位的平均绝对误差。相邻排名用同图相隔4步的6,834对实际状态，比较各自未来净现金增量的顺序，剔除标签平手，预测平手计半分。若比较未来绝对现金差，校准模型两项排序仅53.36%与53.43%。这两种排名都未直接观察同一根状态中两个候选动作的反事实结果。

校准模型相对冻结经济头的地图等权MAE变化为−4.27与−3.37，按地图重采样的95%区间分别为[−10.58, +1.50]、[−14.33, +8.58]。同架构去除收款特征后，误差升至211.29与277.77。加入冻结简化资产价之前的消融为211.91与279.62；两种规格在同一批留图上报告，最终超参数仅根据56张调参图选择。

当某方预计十步入库优势至少100且十步实际净现金有增长时，共有3,008个留图局面，其中716个在35步后反转。该组十步真实净增均值为+240.45，35步均值为−245.73。直接外推入库会报+244.89，完整校准模型仍报+93.80。它缓和了错误的乐观程度，但在事后定义的这批反转样本上，平均预测方向依然错误。

## 嵌入搜索

`experiments.v7.netcash.build(code, weight=.45)` 接受单文件策略源代码字符串并返回可运行的字符串。它在搜索叶子的0.26资产项中，以两头55%/45%的预计现金差作校准。校准前的偏移最多±300现金，默认权重下最多改变资产项135现金，经过0.26外层后最多相当于35.1现金。距终局不足35步时沿用父策略。需同时保留本目录的 `netcash-model.npz`，编译后权重嵌入生成文件。

```python
from experiments.v7.netcash import build

candidate_code = build(parent_code)
```

离线复现使用 `experiments/v7/netcash_data.py`、`netcash_train.py`、`netcash_check.py`；依次在仓库顶层运行。第一步复用原862图入库缓存和能对齐的旧经营特征，后两步拟合并检查实际搜索入口。单次合法决策触发了12次新叶评分。无完整比赛结果，现阶段只能将它列为资产项的小幅候选修正。
