# 第190步局面分叉

真实第190步，QQ-v6 在席0以 3769.49 对 3141.73 领先 627.76。前推10步后，Artemis 实际合计入库 784.39，QQ 入库 128.97；前推20步为 1300.86 对 194.67。第210步 QQ 已落后 605.59，最终以 7113.44 对 7470.23 负于 Artemis。本实验从双方发送第190步动作前开始。第190到210步，QQ相对现金分差下滑1233.35，其中入库差为−1106.18，种树支出差为−312.93，树收益差为+235.74，招募支出差为−90，抢树支出差为+40，另有0.02舍入差。

## 恢复与观测

原局为公开赛事 `03100a95e8647c51a4d642fe08d856dd` 的回放索引1，配置种子 205864169。裁判开局使用了全局 NumPy 随机数，种子不足以复现原始地图。便携输入保存官方第0帧、299套双边动作、300帧校验值；每帧核对双方金钱、工人、树、奖励、整图碳及各席可见碳。恢复第190步时还恢复工人、树和基地的ID计数；随原始动作继续109步得出相同终盘和ID状态。

双方策略通过0至189步的各自视野、公共工人和树、自己实际执行的动作预热。模拟开始后双方各自只读本席当前视野，每回合重新决策。完整碳地图、未来录制动作和地图随机种仅供裁判使用。每次策略内部推演结束后恢复外部裁判的ID计数。

## 对照和干预

基线网络及决策逻辑取自冻结的 `v9-yan-v6-estuary`，提交文件 SHA-256 为 `e5c328aa5d18ced597791e7b839088f1a37d18e4e8dc83dd3d54b13d66e877b0`。为了配对比较，固定每步搜索至多4个根候选、2层、每候选1组对手应手；末段最多对两个保留候选各追加3步。到局终缩短搜索深度。对照和实验均使用这套预算，生产版随实时剩余时间调整搜索。随机种 18011、38039、62047，每种子内按步重置同一随机流。种树、回库、拦截每步最多改两名工人，仅在190至199步启用。200步以后各方继续使用同一基线策略。仅比较同一代理、同一随机种中的干预与控制。

席1的Artemis和Apollo来自同一作者的两个策略嵌入。它们对独立留出回放后期的9440个工人动作预测，彼此只有69个动作不同。另设带温度采样的Apollo代理，扰动由种子、席位、回合、位置和动作确定。三种代理共享底层模仿网络。实际Artemis在20步内入库1300.86；两个确定性代理的三种子控制分别平均入库1148.54、889.43。该局的策略分叉只测量这个已知局面的后续行为，所有胜负仍受代理偏差影响。

## 复核

在仓库顶层使用带 NumPy、SciPy、CPU PyTorch 的 Python。完整的比赛动作已经压缩归档，复核收支和终盘无需重新运行策略网络。

```sh
python experiments/v7/branch_replay.py
python experiments/v7/branch_audit.py
python experiments/v7/branch_summary.py
```

重新生成原始24条策略分叉及一条重复对照，需要冻结版作为顶层 `submission.py`（同一份字节在 `experiments/v6r/checkpoints/estuary.py`）。使用单独的该版代码检出时可直接运行以下命令。

```sh
python experiments/v7/branch_run.py --workers 3
nice -n 15 python experiments/v7/branch_varied.py
```

`branch-results.json` 和 `branch-varied-results.json` 记录各步段的现金及其构成，`deposits` 统计裁判实际增加到基地所属玩家账户的交付额。结果中的步数是动作执行后的状态编号。每个时间点的累计流量均以第190步为起点。`branch-summary.json` 给出逐组配对差值；`branch-actions.json.gz` 保存每条轨迹的双方完整动作。

## 配对结果

下表给出相对同代理、同随机种控制组的平均资金分差变化。终局胜场为绝对胜场数。每一行的地图、出生位和第190步局面都相同。

| 代理与样本 | 干预 | 第200步 | 第210步 | 第299步 | 胜场（控制） |
| --- | --- | ---: | ---: | ---: | ---: |
| Artemis、Apollo 确定性，6组 | 种树 | +22.27 | +132.75 | −167.74 | 6（5） |
| 同上 | 回库 | +623.50 | −140.31 | −428.57 | 3（5） |
| 同上 | 拦截 | +37.52 | +173.44 | −95.81 | 6（5） |

| 同上 | 回库 | +513.16 | −52.67 | +139.56 | 3（3） |
| 同上 | 拦截 | −73.71 | +169.37 | −156.18 | 3（3） |

9组回库干预在第200步都改善资金分差，只有2组到第210步仍优于控制。前一套代理的6组中，回库在前10步平均多入库322.01，后续10步对照赶上，第210步反比对照少入库8.42；带温度采样的3组分别为多329.69和少6.24。树和拦截的20步平均分差均好于控制，但拦截只在9组中的5组改善；全局平均容易被个别分叉拉动，三项干预均缺少跨地图终局验证。
