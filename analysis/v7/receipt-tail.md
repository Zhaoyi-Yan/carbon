# 未来十步大额到款的概率

验证取60张完整留出地图的3,934个队伍局面，实收至少500有589次，至少700有180次。训练另用171张地图；QQ-v6 对 Artemis 第190步所在的整张地图始终独立。每图在开局前按地图指纹指定一个观察席，按时序以该席位的迷雾碳量、公共工人/树和已经执行的己方动作更新原 v6r Belief，再同时预测两方。每九步取样，仅收录完整十步窗口。

对每名采集员分别估计留在原地或先走一格矿区后能带回的碳。先从十步扣去走到矿格和从矿格到任一基地的路程，再按地面碳每步采30%计算所得，附近有可撞赢它的敌方轻车时降低估值。模型分别计入低载工人采后入库的机会、已重载正向基地移动的存货、正连续采矿的工人，以及能否从附近重车获取碰撞货。

| 留出集 | 旧现金预测经概率校准 | 加货量与回程动作 | 再加各矿点产量与可用路程 |
|---|---:|---:|---:|
| ≥500平均精确率 | .709 | .731 | .735 |
| ≥500召回率 / 普通窗口误报数 | 67.4% / 195 | 67.6% / 185 | 69.3% / 190 |
| ≥700平均精确率 | .512 | .511 | .537 |
| ≥700召回率 / 普通窗口误报数 | 77.2% / 244 | 74.4% / 248 | 78.3% / 232 |
| 十步到款现金 MAE | 92.78 | 91.18 | 89.97 |

误报均按「该侧该窗口实际低于阈值」统计。报警概率切点固定为各模型在训练集非事件中的第95百分位。留出集的新模型≥500误报率为5.68%，≥700为6.18%。若把抽样窗口全程都没有达到700的34个队伍对局单列，在1096个窗口中的误报从52次降至35次，受影响的队伍对局从21降至19。≥500这样的队伍对局只有8个，受影响数从1升到2。相对货量/回程动作组，纳入矿区后 ≥700 的 Brier 误差降低，按地图重采样的平均差异95%区间为 −.00153 至 −.00014；≥500 对应区间包含零。原冻结模型完全不校准时，十步现金 MAE 为92.53。

在目标第190步，从 QQ-v6 的合法观测预测 Artemis。现金期望从冻结模型439.90提高到448.03，≥500概率从33.09%提高到39.77%，≥700从4.47%提高到5.36%。按训练集锁定的概率切点，旧模型未触发≥500预警，新模型39.77%越过37.99%的预警线。实际入库784.39，≥700概率仍低于10.49%的预警线；模型能发出较低一档的预警，仍低估了金额。

独立插件 `receipt_tail.build(code)` 提供按棋盘缓存的 `_v7_receipt_tail(board)`。返回两行，按座位排列，每行依次是≥500与≥700的概率、十步到款期望、超出500的正部期望。距终局少于十个行动时返回 `None`。只有显式调用才会计算。特征新增用时中位约0.11毫秒，P95约0.30毫秒。资格候选未调用此模型。
