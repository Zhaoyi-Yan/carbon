# 用固定随机种子预测 v6 的应手

冻结的 v6 用 MT19937 种子 37 在每回合按字典顺序给每座基地、每个工人各抽一次。无钱招聘和强制返程照样消耗随机数。搜索另起按回合和座位决定的随机流。v5 也用 37，根采样温度是 0.40，v6 是 0.30。

在四张本地图和四张公开图的前 64 回合逐步重建，512 次随机状态核对全部相同。在这八张图的 3,285 个工人动作上，若能读取 v6 自己的真实可见盘面和根 logits，重建的采样与去冲突后的根初案有 99.33% 一致，与比赛最终指令有 90.20% 一致。直接取最大概率是 88.83%，安慰剂种子 36 是 87.00%。这组回溯只用于定位推断上限。

## 对手视角的独立留图

实际模块只能读取观察者的公开状态和原有 Fairlead 对手 logits。使用 24 个训练布局选出有效温度 0.40、分位点对称反射扰动半宽 0.14、混合权重 0.16。这里的有效温度校准的是对手视角代理本身。评测保留 11 个布局，含本地 8 个换边座位及 7 个官方完赛 v6 座位，合计 10,395 个工人动作。资格种子和两个问题对局的布局全部排除。错误种子使用完全相同的参数、行动顺序和权重。

| 面对真实 v6 | 记录动作 NLL | 命中率 | 给实际指令的平均概率 |
| --- | ---: | ---: | ---: |
| 原有 Fairlead | 0.39396 | 87.20% | 84.18% |
| 已知对手身份后直接用 37 | 0.39111 | 87.45% | 84.43% |
| 实际插件按开局和既往移动识别 | 0.39261 | 87.25% | 84.25% |

实际插件在这些地图上的 NLL 差值均值 95% 地图重采样区间是 [−0.00218, −0.00086]。直接用错种子 36、38、71 时，每工人 NLL 分别恶化 0.00634、0.00509、0.00385。对 223 次持货至少 65 且最终偏离原首选的决策，插件给最终走法的平均概率从 22.77% 升至 23.01%，已知身份版本为 23.86%。最优备选方向的命中率从 79.37% 变为 78.92%，显示收益主要在概率分配。这个子集是在看到真实标签后划分的。

## 相似开局和错误识别

正式插件从第 1、2 回合公开工人数、工种和种植员出生位置检查反应式开局，结合原有 v6 行为分类器，以及之前仍然存活的单位实际动作对分位点模型提供的似然证据。遇到观测回合断档会放弃本局估算。

15 个 v6 留出座位全部符合开局，配对的 15 个其他座位都没有符合。另查 862 张历史公开图的 1,724 个座位，共 36 个出现相同足迹，其中 Artemis 34/48、Prometheus 2/4。再对独立抽出的十张 Artemis 图和两张 Prometheus 图重放实际动作，凭开局直接启用会恶化 NLL 0.00675。加入历史行为后，平均权重降到 0.0047，NLL 恶化 0.000026。档案为便利样本，其中强手占比与实时匹配概率不同。

## 连续实盘冒烟

单文件模块在十个座位从第 0 至第 127 回合连续重放，逐步通过 1,280 次随机状态核对，另进行一次实际根搜索。单核额外耗时中位数 0.123 ms，95 分位 0.355 ms，99 分位 0.611 ms。四张 v6 图的 NLL 合计改善 0.00134，其中两张线上图改善 0.00274，两张本地图合计恶化 0.00011。四张 Artemis 图、一张 Prometheus 图及 v5 座位的 NLL 差值均四舍五入为零。这项连续复核与上述留图有重叠。

## 复现

下列脚本读取之前已归档的 distill-cache 等工作缓存，所有命令均在仓库根目录执行。训练和验证可在单核 CPU 上运行。

```sh
python experiments/v7/quantile_data.py ../v7-data
python experiments/v7/quantile_fit.py ../v7-data
python experiments/v7/quantile_oracle.py ../v7-data
python experiments/v7/quantile_open.py ../v7-data
python experiments/v7/quantile_stress.py ../v7-data
python experiments/v7/quantile_operate.py ../v7-data
python experiments/v7/quantile_live.py ../v7-data
```

生成器为 `experiments/v7/quantile.py::build(code)`，需要父策略已有 `_ds_class_reply`。报告的验证单位是工人动作概率。胜负需要在新的整图双座位对抗中另行检验。
