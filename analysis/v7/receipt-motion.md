# 同一工人前两步的动作能否预测到款

对177张训练图和原冻结入库模型的155张完整验证图，以每六步、两个席位取样，共15,400个验证方次。按工人ID追踪最近两步相对最近基地的进退、连续停留、停下采矿后的增货、移动碰撞后的增货，以及载货下降。用这些特征修正原入库预测。单独增加现金/时间的重新校准，作为对照。原冻结模型、残差拟合和频率校准都没有使用 QQ-v6 对 Artemis 的目标图。

| 验证指标 | 旧模型5步 / 10步 | 只做重新校准 | 加工人近期动作 |
|---|---:|---:|---:|
| 到款额 MAE | 52.85 / 92.02 | 53.13 / 92.42 | 52.46 / 90.72 |
| 到款额 RMSE | 84.22 / 135.52 | 84.14 / 134.85 | 82.55 / 131.34 |
| 至少一次到款 AUC | .8505 / .8143 | .8496 / .8129 | .8534 / .8218 |
| 到款频率 Brier，越低越好 | .1364 / .0776 | .1372 / .0794 | .1360 / .0786 |

相对旧模型，5步与10步在60/155和86/155张图降低了 MAE。按整图配对重采样，5步平均 MAE 变化的95%区间为 −1.02 至 +0.16，10步为 −2.27 至 −0.47。10步的现金误差有小幅改善；频率概率的10步校准变差。加入历史后，预测5/10步平均到款为125.92/251.96，实测129.12/257.55，整体仍有低估。

第190步实局，Artemis 之后5步入库178.56，旧模型预测300.52，动作修正后293.89；10步实收784.39，预测439.90变为447.39。四名工人当时共携482.57，后续实际采矿236.25和碰撞夺货65.57。第44号当时空载，之后拿到65.57碰撞碳、25.78矿碳，最终交91.35。目标图全程 MAE 的5步47.46→47.30，10步75.04→75.32。动作趋势无法单独预见这次集中入库。

独立插件 `receipt_motion.build(code)` 在根部读取自己的前两次公开状态，模拟中从父棋盘传递前序状态。每块棋盘只计算一次，同时预测双方；新增特征用时中位33微秒、P95为98微秒。未进行整局胜率评测。

复算时可通过 `--target` 指定下载的官方 HTML 或 gzip 回放。训练与验证比赛指纹见同目录的 `receipt-games.jsonl`。[目标局官方回放](https://117.72.210.134/replay/03100a95e8647c51a4d642fe08d856dd/1)
