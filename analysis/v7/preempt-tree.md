# 提前拦种、换树与调整招募基地

Soundings 在种子 590159492 两次惜败，席 0 差 5.26，席 1 差 40.20。我们从该图两边和 Pilotage 的两张双负图中还原全部树权转移，另用公开实盘做整图留出和短窗配对。胜负与分数均保留在原资格赛记录中。以下分支只演到第 18 步，现金效应是处理组相对基线的**双方现金分差变化**。

## 提前几步能看见风险

从 862 张公开地图的已有索引中，按固定的初盘哈希顺序取 120 张训练、42 张验证，排除单独分析过的截图回放。每隔四步观察双方近库六格内有产出、尚有寿命的树，记录最近敌方种树工与树的距离、上一回合接近方向、双方工人距离、树龄、当前分账及双方基地距离。在验证图中，6,247 个合格树状态有 684 个在五步内被夺。完整模型和仅用工人距离的模型分别得到 0.08009 和 0.09367 的 Brier 分数，0.27823 和 0.32596 的对数损失。

敌方种树工正在接近、仍相距 2–4 格的 2,628 个状态中，277 棵在随后第 3–5 步被夺。按预测概率取前四分之一，实际被夺率为 25.11%，距离基线为 15.50%。多个时点可能对应同一棵树，数据按整图划分。在实际 Soundings 双败图两席，近库被夺 17 和 16 次，其中各 13 次能提前 3–5 步看见正在靠近的敌工。风险预测的指标和行动结果分别评估。

## 派现有工人

给当前策略一个新联合动作，每次只改一个工人。轻载采集员可以提前截断种树工的最短路、占住受威胁的树，也可以由己方种树工换取另一棵有收益的敌树。安全条件满足时最多跟进四个决策。按事前观测选取每张图的一个时点。先用空动作表筛出能够提出行动的局面，再与冻结的 Soundings 联合决策比较。已有计划覆盖目标或候选选择相同走法时保留原行动。

## 改变已出资工人的出生地

Soundings 双败图席 0 第 209 步，敌方种树工距本方 130 格的树四步，最近的轻载采集员距树五步，己方仍有一个工位。历史策略在距树十步的 64 格基地招募采集员，160 格基地距离仅两步。当时风险预测约 17.15%。原局第 214 步树被夺，敌方此后 18 步从该树获得 66.10。这个时点是事后选出的机制诊断例。

候选仅在本来就要招募采集员时换一个未使用的基地，同时检查己方重车入库和轻敌位置。不会新增招募费。与历史原动作对比，改从近库出生且只指挥新工人最多三步后，树仍然在第 214 步被夺。到第 227 步己方和对方现金由原来的 5,020.33 对 5,675.07 变为 4,952.71 对 5,703.53，分差恶化 96.08。历史路线只能对仍存在的同 ID 工人生效，产生六个与原局工人 ID 不匹配的工人回合。

让双方重新决策后，同一局面的第 5、12、18 步处理效应依次为 −226.05、+84.29、+20.77。第 18 步入库分差增加 72.45，目标树的净分账反而少 11.70，相对持有时间少四个回合。局面的净收益不能解释为该树得到保护。

### 另取整图验证招募换位

预先按另一哈希顺序固定 85 张地图，全部与上述 162 张剥离。按真实当步的已出资招募及出手前可见的棋面筛选。79 图没有达到规则门槛，六图各挑一个符合条件的时点。冻结 Soundings 在其中三图仍作出可被重定向的远端招募，另三图保持原动作。实际三个处理的第 18 步效应为 −23.06、+63.81、−212.71，平均 −57.32；按六个入选时点平均 −28.66。在全部三次改派中，目标树相对持有回合均无变化。第 5 步的平均效果原为 +84.56，到第 12 步已转为 −79.03。样本很小、动作触发较少，现有证据支持保留冻结策略。

## 裁判、对手与复现

每个状态用官方裁判从公开初盘及其真实动作重放。程序比较双方工人、树、完整碳图、两席各自可见碳图和双方分数直到所选时点之后第 18 步，重新决策前还原实际工人和树的 ID 计数。模型只获得比赛席位能看到的输入。本地资格赛原始记录另逐回合复核双方现金并核对原终局比分。公开原局的续步只用于还原检测及单独标明的历史路线压力测试。

实时分支沿用 Soundings 权重和功能，将首次根搜索固定为四候选、深度上限二、一种对手回复和三步尾评估。之后双方逐回合使用同一套免搜索的模型根，策略对手固定为 v6 Estuary。处理组、基线使用相同按地图、步数和席位编排的策略随机种。没有采用原历史对手作为实时对手。得分仅衡量这套固定预算下的机制反事实。
