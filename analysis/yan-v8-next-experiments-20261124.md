# yan-v8：最新实验结论与下一轮执行计划

日期：2026-11-24（北京时间）

用途：供 Codex 拉取后继续研究、实现和测试。本文是实验交接计划，没有新增策略晋级或新增对局结果。

## 先执行什么

**第一批只做四个固定局面的评分分解：两个第二候选更好的案例，配两个反例。先定位排序差异来自神经价值、经济估值、动作先验、尾部续局，还是对手回应；再选择一个部件做受控修改。**

后续主线是验证实际部署分布上的终局价值校准，以及关键对手回应的覆盖。通用种树门槛、持续守树、提前回款和统一选择第二候选，均未获得可晋级的证据。

本文的执行顺序：准备代码与数据 → A：评分分解 → 根据证据选择 B：价值校准或 C：对手回应实验 → 新地图整局确认。B、C 是后续路线，不要求同时实现。

## 2. 最新结果改变了什么

所有“改善”均指替换动作后，相对基线的我方减对方终局现金差变化；不是天梯胜率。

| 实验 | 已观察结果 | 应采取的更新 |
| --- | --- | --- |
| 持续树任务：8 根、两种本地代理、16 对 | 持续任务比只改第一步 +91.52，但相对原 v8 −211.76；48 条续局完成 | 这套局部守树控制器降优先级；不能将中间对照的改善当作完整方案提升 |
| 回本筛选：9 根、18 对 eligible 干预 | 全体 +16.18；11 次成功种树全部活满 50 回合、回本，对应终局均值 −206.30 | 单树回本不能直接充当最终动作价值 |
| 联合动作：12 根、8 张独立地图 | 树面板 plant −54.51、defer −62.60、runner-up −14.19；残局 bank −112.75 | 缺少某个动作不等于缺少好动作；继续扩候选前先定位评价问题 |

来源：[E1] · [E2] · [E3]。12 根、96 条动作臂记录、65 条不同终局轨迹不能当作 65 张独立地图。

### 2.1 回本实验的关键分解

| Eligible 干预后的结果 | 配对数 | 平均终局差变化 |
| --- | ---: | ---: |
| 成功生成新树 | 11 | −206.30 |
| 改为停留但没有生成树 | 4 | +640.15 |
| 与队友冲突而保留原动作 | 3 | 0 |
| 全部 | 18 | +16.18 |

11 棵成功树的普通收入减成本平均 +50.29；全队相对树净收入却下降约 139.55，相对归仓下降约 20.41，相对招募开销增加约 46.36。不能继续主要用“树没活够、没回本”解释这组失败。[E2]

四次未种成的分支第一步均出现双方各死亡一个单位，baseline 无死亡。它们改变了碰撞与后续局势，不能把其收益归功于种树成功。这里按干预后的结果分组，仅用于机制诊断；成功组 −206.30 不是无条件策略效应。[E4]

回本诊断器训练的是“已成功出生的树在首次持有期间是否回本”，没有把尝试停留却当场死亡的情况作为失败尝试标签；其 65–244 回合训练范围也未覆盖最初开局与最后阶段。[E2] · [E11]

### 2.2 短期指标不适合单独决定晋级

新增 plant 候选 20 步现金差平均 +25.41，终局却 −54.51。持续任务相对原 v8 在 35 步有 10/16 个案例现金差更好，终局只剩 5/16。Master 第 250 回合的提前回款候选，在两种敌方首步下终局分别 −278.86、−100.98。[E1] · [E3]

短期现金、载货、树收益用于解释过程；最终验证仍需终局结果。不能由“20 步更好”直接生成硬性的正确动作标签。

### 2.3 证据边界

- 持续任务与回本实验由本地 v7/v8 闭环响应；每个代理还绑定不同随机流，代理差异与随机流未完全分离。
- 联合动作实验对比自然 v8 首步与真实历史首步，之后双方都使用本地 v8；不是前六真实策略的完整反事实续局。
- 受控预算为 width 4、depth 至多 2、一个内部对手回复、三步 tail，关闭真实墙钟中止；它验证固定搜索形状下的行为，尚未验证线上等时限收益。
- 树根局面集中在有争夺的区域，不能推广成所有种树场景的结论。
- 本轮没有新增对最初 0–60 回合的充分验证；开局受压仍需独立覆盖。[E1] · [E2] · [E3]

## 4. B：单独验证终局价值校准

### 4.1 可检验的假说

当前 elite-refit 的新监督值为：

$$
y^H_t = [0.28 D_{\min(t+20,T)} + 0.52 D_{\min(t+52,T)} + 0.20 D_{\min(t+100,T)}] / 3000.
$$

其中 D 为当前视角下双方现金差；训练目标再混合 0.65 的旧 critic 输出和 0.35 的新标签。这是 refit 的监督目标，不代表运行时全部组合评价。[E7] · [E7a]

待验证假说：在 v8 实际访问的候选后继状态上，终局现金差监督能改善候选排序，而非只改善中期现金拟合。新三轮实验尚未直接验证该假说。

### 4.2 最小受控比较

| 组别 | 变化 |
| --- | --- |
| B0 | 原始冻结 v8，保留所有已发布权重与评分 |
| B1 | 固定策略编码器与其他部件，仅校准相同 value 层；使用旧式中期标签 yH |
| B2 | 与 B1 完全相同的数据、初始化、训练预算、选模方式与 value 层；只将新标签换成 yT = D_T / 3000 |

yT 在首轮使用同尺度的终局现金差除以 3000，不同时换成含胜负符号项的 `_terminal(D_T)`，以免把评分尺度变化混入时域对照。

B1、B2 都先保留相同的 0.65/0.35 旧值锚定系数，避免同时改变目标时域和锚定强度。也不同时加入新动作排序损失、win head、网络扩容或新的评分融合。后续确有需要，再分别消融。

只比较 B0 与 B2，可以衡量整个价值改动，但不能区分新训练数据与终局标签各自的作用；B1 是必要的同预算对照。

### 4.3 数据与评估

- 数据来自真实可恢复根和 v8 候选后继状态，输入使用运行时合法的观测/历史估计；完整回放状态可用于环境推进、标签和核验，不泄漏进策略输入。
- B1、B2 的两种标签从同一组冻结 B0 的闭环续局计算；训练期间不分别使用各自的新 critic 重新生成数据或标签，以保持仅改变监督时域的对照。
- 预先固定训练、验证、测试的整场与地图清单。同一地图的不同回合、候选、随机流、双方视角属于同一组，不跨集合。
- 同根不同动作使用配对续局；对手版本与随机流交叉，不再让每个代理只绑定一条不同随机流。先做小规模试点，记录每项算力开销后再扩充。
- 基线在分叉后重新闭环响应；强制首步后同步执行历史与记忆。保留未成功种树、动作被挡回、零变化、超时和败局，避免按结果筛掉不利样本。
- 关注相对动作优势：A(s,a) = E[D_T | s,a] − E[D_T | s,a_v8]。候选收益方差和符号不稳定的样本不能作为确定的正确动作。
- 评估实际部署路径，并将 general 20 与 teacher 27+ 监督切片分开。当前 own 主入口为 20；不能用已知 teacher 身份下的 NLL 代替运行时指标。[E6] · [E7]
- 除预测误差外，报告未查看地图上的候选排序、所选动作的配对终局收益，以及多对手/随机流下的稳定性；按地图聚合。开发四根上的改善不计入泛化结果。
- 新根按开局 0–60、中盘、后期事先分层，避免继续只围绕争夺树局面取样。

若 B2 相对 B1 没有稳定优势，就不能声称终局标签更好。若局面指标有提升但完整策略反复使用后整局退化，则不晋级；需要分析访问分布和后续选择的变化。

## 5. C：关键对手回应与前六/前十数据

继续收集前六对所有人的对局，特别是前六互相对战，并保留败局。前六作为核心目标分布，前七到前十作为补充与泛化检查，保留精确策略 ID、对手、阶段和地图，而非全部混成同一种老师。

优先检验当前对手回复集合能否覆盖：抢树、同格碰撞、关键回款路线受阻、放弃局部收入以保留人员或位置。检验的是影响候选排序的局部事件及其联合关系，不要求逐字匹配整队每个动作，也不只看整体动作 NLL。

当前对手主路由使用旧 0–19 后验或不确定时的 20，并有 shadow/DS 修正；27+ 新 elite 行没有对称进入对手主路由。此前加入 21/22 的旧实验仅获得极小预测变化，所以“接入高手 embedding”本身不是有效性证据。[E6] · [E8]

C 阶段先做未查看回放上的关键事件预测与候选排序敏感性分析；只有确认缺失的回应确实影响决策，才实现一个最小回复覆盖改动。固定我方策略与价值，单独测试它。推理时只使用当时可获得的信息；真实历史动作仅用于离线验证。

## 6. 整局确认与交接要求

沿用 main 的 [AGENTS.md（审查时固定版本）](https://github.com/Zhaoyi-Yan/carbon/blob/155dcc5275b8a23a223769346cc7c00661e36155/AGENTS.md) 与 [ARENA.md](../ARENA.md) 的已有流程：对冻结的当前主力，用同地图换边完整对局比较；晋级前再使用开发时未用的多张地图确认。记录逐局分差、两席结果、败局、超时、文件哈希和耗时。实验工作树中的旧版基线描述与已发布版本不同，本轮对照始终使用第 1 节的冻结 v8；接手时另行核对 main 是否已有更新的维护要求。

受控 continuation 的固定搜索预算与真实线上时间预算分开报告。通过局面诊断不等于通过整局晋级，本地代理收益也不等于真实前六对战收益。

每轮完成后将该轮实验代码、协议与已有结果一起提交、推送到实验分支；主分支策略更新和版本标签只用于实际采用的版本。排行榜上传仍按仓库维护流程处理。
