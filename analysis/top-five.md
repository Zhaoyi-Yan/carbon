## 怎样使用这批回放

与 v5 使用过的 21 场 Apollo 回放按地图种子核对，有 14 张地图重合，63 张地图是新增样本。训练与验证按初始地图指纹分组，两边动作和同一地图上的所有帧进入同一组。初始全图仅用于离线去重，训练时应重建玩家当时看得见的资源。若把这里分析过的 63 场用于探索，检验泛化能力要另留冻结的新回放或新随机种子。混合策略训练时保留对手 ID、动作所属方及败局，按策略分别核算成绩。

## 复算

本仓库的 [replays/top-five](../replays/top-five) 保存了这 77 场压缩的完整原始回放和对应的官方索引条目。可在项目根目录离线复算，脚本只依赖 Python 标准库。若使用更新的官方快照，比赛和排名可能发生变化。

```sh
python3 analysis/top_five.py replays/top-five > /tmp/top-five-games.jsonl
```

每一行对应一张不同地图。seats 数组按实际 0、1 号位排列，利用官方 order 将策略 ID 和终局奖励对齐。score 为裁判奖励，cash 为账户资金，提前结束时二者可不同。map_sha256 对棋盘尺寸、双方基地和初始资源分布取指纹；遇到重复地图时保留按对局 ID 和局号排序后的第一场。early_empty_collectors_near_enemy_base 统计第 1–75 步，terminal_cargo 为终盘尚未回款的载碳，lost_worker_cargo 为消失前一帧的载碳（包括可能被队友回收的份额）。
