# 在搜索中复用己方行动模型

v5 的真实回合先用回放训练的行动头给工人和基地打分，搜索到了下一步却用早期的 Master3s2 行动头模拟自己的后续走法。候选在搜索需要推进棋盘时，把己方的隐藏特征送入 v5 行动头。对手的走法、价值网络、树木收益预测、回程规则和搜索预算沿用 v5。已有卷积结果会在同一个批次复用，无须再推理一次主网络。数值核对覆盖标准 Torch 和 Winograd 两种 CPU 后端，敌方行动分数完全一致，己方与单盘 v5 行动头的最大绝对误差小于 0.00024。

## 对实际走法的验证

从 yan-v2 公开的完整对局中取 18 张不同地图，每三步抽一帧，用该席位当时可见的观测重建碳量，再生成与搜索一致的输入。下表比较单个工人或基地的首选动作，与实战联合搜索后真正执行的动作一致的比例。这组回放用于验证，两个行动头在验证前都已冻结。

| 单位 | 动作数 | 原模拟行动头 | 复用 v5 行动头 |
| --- | ---: | ---: | ---: |
| 采集员 | 13,914 | 79.66% | 81.65% |
| 种植员 | 2,307 | 69.14% | 72.00% |
| 可招募基地 | 766 | 80.94% | 84.60% |

18 张地图上采集员命中率都变高。动作预测更接近实际走法有助于检验设计动机，最终强度仍由独立换边赛检验。搜索内部的采样和落点避让会影响实际行动。

## 换边结果

在预先选定的新地图 26117，候选坐 0 号位以 7894.29 比 7186.74 获胜，坐 1 号位以 7240.40 比 7963.86 落败。两局均到第 299 步，候选平均资金分差为 −7.96，双方均无慢步、超时或异常。该样本的现金结果支持继续使用冻结的 v5。它同时给出了一个反例：更准确地预测自己的下一步动作，未必能改善搜索最后选出的当前动作。[逐局台账和动作对照原始计数](own_rollout_results.json)

## 复现

```sh
python experiments/own_rollout.py --output /tmp/own-rollout.py
python experiments/own_rollout_check.py --snapshot /path/to/replay-snapshot \
  --candidate /tmp/own-rollout.py --output /tmp/yan-rollout-actions.json
python arena.py --strategies own-rollout=/tmp/own-rollout.py v5=submission.py \
  --seeds 26117 --jobs 2 --output /tmp/own-rollout-26117.jsonl
```
