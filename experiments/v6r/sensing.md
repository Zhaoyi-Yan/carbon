# 用树的本步实收推断视野外碳量

yan-v5 已用自己看见的碳、工人的移动和地图的初始镜像更新估计。这组候选再使用公开观测中的每棵树本步收入。前 75 步，区间版在两批互不重叠的 72 张回放地图上，将全部视野外地块的平均绝对误差分别降低 1.441% 和 1.192%。这些离线结果衡量视野外的估计精度，实战收益需要换边比赛衡量。[第一批 72 图](sensing-intervals-validation.json) · [第二批 72 图](sensing-paired-validation.json)

一棵成熟树的收入包含周围地块的吸收和附近敌采集员的载碳税。一个采集员可能同时被多棵树抽税。根据公开的工人位置、树龄、树主和税率，用其可见的税后载碳除以剩余比例，还原税前载碳，从该树实收中扣掉对应税款。树下及八邻格的敌采集员都计入。只用四邻格的地块收入，排除树格与静止采集员占据的格子，新种的树在当步免计。对同时被多棵树吸收的格子，按实际树数还原每笔收入对应的吸收前碳量。[裁判树收入计算](../../vendor/zerosum_env/envs/carbon/helpers.py)

- **精确解版本**遇到地块收入为零、或仅剩一个未知格时，结合该格至今经历的生长、采集和吸收运算，检查是否只有一个整数初始碳量与观测相符。得到唯一候选后，更新同一初始镜像组。
- **区间版本**对含多个未知格的收入方程，结合每个格子的可行范围进一步收窄上下界。只调整已落在可行区间以外的先验估计。
- **交叉确认版本**遇到已在己方视野外、估值来自旧 Belief 的邻格时，要求第二棵树对同一初始镜像组给出相同的整数解，再执行永久更新。零地块收入可直接判零。开发过程中发现，原 Belief 偶尔会把曾经追踪过的格子标为已知，但其估值已偏离真值，差额会被错误归到最后一个未知格。

## 配对评测

从 217 个不同布局按固定哈希排序取样，每图固定一席，到第 150 步或裁判提前终局。对照双方只接收该席位实际可见的碳、公开玩家及树状态，以及已执行的本方历史动作。计算误差时才读取全图真值。统计单位为视野外格子 × 回合，同一格持续多步会多次计入，地图和对手之间的差异会影响量级。

| 地图批次 | 候选 | 第 1–75 步基线 → 候选 MAE | 第 76–150 步基线 → 候选 MAE |
| --- | --- | ---: | ---: |
| 前 36 张 | 精确解 | 5.453311 → 5.419018 | 0.041199 → 0.040765 |
| 随后 72 张 | 区间 | 5.486763 → 5.407690 | 0.072283 → 0.074277 |
| 再后 72 张 | 区间 | 5.710778 → 5.642683 | 0.120875 → 0.117172 |
| 同一批再后 72 张 | 交叉确认 | 5.710778 → 5.691675 | 0.120875 → 0.120689 |

最后一批同图配对中，前 75 步新标为已知的格回合，区间版 MAE 从 28.997 降至 0.205，交叉确认版从 28.333 降至 0.008。后者覆盖的格子更少。在本机单进程、单线程 BLAS 核对时，此批区间版每步额外耗时第 95 百分位为 0.056 毫秒。第二批地图在中盘出现小幅退化，保留在上表。[精确解结果](sensing-validation.json) · [交叉确认结果](sensing-confirmed-validation.json)

## 复现

从仓库根目录运行。DATA 指向[回放复建说明](artemis.md)所用的缓存目录。本轮对照使用 yan-v5，基线文件 SHA-256 为 `0a413a11f80f6872a5c8f0d313061d7bf11121ae16fbdad97247ff3cb15242e5`。同一个生成器也可应用到保留原始 belief 更新入口的实验策略。

```sh
python3 experiments/v6r/sensing.py --base yan-v5.py --output /tmp/sense-exact.py
python3 experiments/v6r/sensing_intervals.py --base yan-v5.py --output /tmp/sense-intervals.py
python3 experiments/v6r/sensing_intervals.py --confirmed --base yan-v5.py --output /tmp/sense-confirmed.py
python3 experiments/v6r/sensing_check.py --candidate /tmp/sense-intervals.py --data "$DATA" \
    --offset 108 --maps 72 --output /tmp/sense-checked.json
```
