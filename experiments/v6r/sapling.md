# 刚种的树值多少钱

一棵树在种下当步的实际收入为零。原资产模型把上一回合树收入作为未来估值的主要输入之一，因此很难仅凭第一帧区分两棵新树。45 张独立比赛地图上的 2,560 棵新树，原估值与后续实际折现收益的相关系数为 0.312，加入周围地面碳与争夺特征后升到 0.581。[完整评测及地图](sapling-model.json)

| 当前树龄 | 测试树或树回合 | 原估值 MAE | 新估值 MAE |
| --- | ---: | ---: | ---: |
| 1，当步新种 | 2,560 | 33.46 | 25.16 |
| 2–3 | 5,117 | 28.31 | 24.91 |
| 4–6 | 7,657 | 25.60 | 23.40 |
| 7 及以上，每 30 步抽检 | 3,611 | 9.03 | 9.03 |

按训练集中年龄 1 树的邻格预期吸收量划分四分位。高产组 550 棵测试树后来实际赚到的折现净收益平均为 76.87，原模型估 31.41，新模型估 80.29。低产组 684 棵平均为 25.72，原模型估 27.48，新模型估 21.42。高产组 MAE 从 58.04 降至 30.65，低产组从 20.03 降至 17.99。单加四邻地面碳、其他树的重叠吸收和静止采集员的占位，就能将所有新树的 MAE 从 33.46 降到 25.26，再加敌方携碳交通和双方工人的位置后为 25.16。

逐树标签沿用旧模型，累计此树从下一回合开始的实际吸收收入，每步乘 0.968。易手后，给当前视角的对手挣到的收入记负，直到树枯萎或比赛结束。训练取原资产模型使用的 172 张图，45 张测试图均未参与两模型的拟合。先在 12 张测试图查看初步结果，其余 33 张后来单独核算，新树的 MAE 从 33.97 降至 24.96。按地图单独统计年龄 1–3 的树回合，45 张均改善。同一棵树可能在不同树龄多次计入。

每张图用哈希指定一个观察席位，两方树木均从该席的合法碳估计取特征。对四邻的每个可吸收地块，估算若当前位置的竞争树仍在，剩余时间能从现有碳量中吸收多少。采集员上一帧与当前同格时单独计入占位阻挡。敌方载碳和上一帧移动方向用于估计潜在树税。模拟搜索沿用每个候选盘面自己的估计碳图。只修改树龄 1–6 的树估值。

已在 120 个模拟搜索叶子上对照原资产分数与新估值逐项重算，最大误差 3.33×10⁻¹⁶。估值变准对对战胜率的影响需要本地换图换边检验。[入口与公式核验](sapling-check.json)

```sh
python3 experiments/v6r/sapling_fit.py --data "$DATA" --cache /tmp/sapling-rows --output /tmp/sapling-model.json
python3 experiments/v6r/sapling.py --base "$GROVE" --model /tmp/sapling-model.json --output /tmp/sapling-grove.py
python3 experiments/v6r/sapling_check.py --data "$DATA" --candidate /tmp/sapling-grove.py --base "$GROVE" --model /tmp/sapling-model.json --output /tmp/sapling-check.json
```

DATA 指向[公开回放的本地缓存](artemis.md)，GROVE 指向启用了资产估值的单文件策略。此次使用的输入文件 SHA-256 为 `dc4884bf658d7b1d1920b3dea17cec8abe169f78198d2cbef3548e4fc52466e0`，导出策略为 `4d0555dde9756f599bc596d72d2673372bde00ce8a77e3ad553422d3376aea4e`。
