# 高载碳采集员会走哪一格

对手的行动是搜索中的一个假设。v5 先用神经网络预测敌方工人，再从预测分布取样推进棋盘。这个实验分别检查首选方向的命中率和备选方向的预测概率。两者影响搜索的方式不同。

训练目标是 Apollo 每个携带至少 75 碳的采集员下一步在哪个方向移动，原地停留算第五个动作。所有预测输入都从 Apollo 对手的可见信息重建，包含公开工人、树、基地和观察者自己的部分可见碳图。回放的完整开局碳图仅用于识别重复地图。动作标签取下一帧，保留碰撞和阵亡前的行动。按初始布局和地图种子去重，再以整张地图为单位分为五折，每一折用另外四折拟合。

在 21 张 Apollo 地图共 12,112 个决策中，v5 原始方向首选命中 79.26%。它的平均负对数似然为 2.345，数值越小表示给真实动作的概率越高。只为原模型拟合一个温度就降至 0.535。再加入回家距离、上一轮方向、是否可能遇到轻装对手等特征后降至 0.517，首选命中 79.70%。这些是交叉验证的单工人动作指标。游戏中的联合行动还会根据基地招募和各工人落点解决冲突。

其中 4,502 个决策存在双方工人可能接触的机会。具体条件是敌方载货工人有至少一个下一步落点在其基地以外，观察方一名载碳更少的采集员也能在一步内抵达该格。此时 Apollo 选择靠近其最近基地的比例为 56.1%，其他局面是 40.1%。这种差异还会受到位置和库存分布影响，不能直接推断主动逼近会造成同样的变化。

## 换一个对手

同一批 Apollo 拟合的参数直接预测 claude-AlphaCarbon-Master7sD，在 14 张不同布局、不同种子的地图中得到 7,538 个高载碳行动。原 v5 先验、温度校准、Apollo 战术模型的平均负对数似然依次是 5.273、0.865、0.886。首选方向命中依次是 71.13%、71.13%、70.58%。温度校准带来的收益延续到了第二位强手，而在这一组样本中，增加针对 Apollo 的特征会损失部分精度。训练与外推涉及的每个地图指纹、比赛编号和相应指标见[研究数据](route_forecast_results.json)。

## 换边对战结果

用兼容旧版的 benchmark 计时方式，以种子 17471 对 v5-tree-value 跑了两场完整的 299 步比赛。Apollo 战术版坐 0 号位以 4629.35 比 4407.91 获胜，坐 1 号位以 4321.79 比 5429.48 落败。结果是 1 胜 1 负，平均分差 −443.12。两局 v5 各完成 298 次搜索，候选最慢单步 0.863 秒。在隔离竞技场，温度校准版在同一地图的 0 号位输 548.69，1 号位输 362.77，0 胜 2 负。两局双方都正常结束，每局均完成 298 次搜索。两种候选均保留作实验。两组采用不同计时工具，应各自与当场 v5 对照。[温度版逐局记录](../analysis/arena/temperature-17471.jsonl)

## 在竞技场复测

```sh
python experiments/route_forecast.py --report /tmp/routes.json --candidate /tmp/route-opponent.py
CARBON_DEBUG=1 python benchmark.py \
    --candidate /tmp/route-opponent.py --opponents submission.py --seeds 17471 --jobs 2
```

拟合脚本会生成结构与 v5 兼容的单文件候选。默认使用战术特征。加上 `--profile temperature` 可导出只校准置信度的对照候选。它只在标准规则下为第一步敌方高载碳采集员调整行动分布，后续搜索层沿用 v5。导出文件使用全部 Apollo 地图训练，独立的概率指标来自分折训练。输出路径需使用新文件名，以免替换已经测试的候选。要检验换一个对手后的外推能力，可增加 `--external-replays`（含 index.json 和 replays 目录的官方快照，或本仓库式 manifest 目录）与 `--external-target`（精确策略名）。外部评测剔除已经参与拟合的地图布局与种子。完整换边赛单独检验这种调整对己方胜负的影响。
