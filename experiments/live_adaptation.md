# 按对手行为和剩余步数调整打法

实验基线是已提交的 yan-v3。候选仍是一个可独立运行的 Python 文件。当前对手的名称、源码、下一步指令和隐藏碳图都不参与决策。每局第 0 步重新建立对手记录。[策略改动](https://github.com/Zhaoyi-Yan/carbon/commit/ef3c0b3)

- 对手有载碳至少 75 的采集员时，记录原模型预测的“下一格是否更靠近其最近基地”。下一帧若同一个工人仍在场，才用实际位置更新预测偏差。把两格内有更轻的敌对采集员和没有这种压力的样本分开。旧记录每步乘 0.96，八个中性伪样本抑制小样本波动。调整仅作用于搜索根节点模拟的敌方行动。
- 最后 69 次决策中，按现金差和双方仍可交付的载碳估计领先程度。若同一候选有两种模拟对手应答，领先时提高较差结果的权重，落后时提高较好结果的权重。幅度随领先程度和剩余步数连续变化，只有一个模拟结果时直接使用该结果。
- 若接近终局、预计领先，且载碳至少 75 的工人身旁两格内有更轻的敌方采集员，允许它最多提前六步启程交付。沿用原版对距离、能否按时到家、敌方威胁和己方落点冲突的检查。常规局面继续使用原来的三步余量。

另外重放仓库归档的前五选手对局，逐座位、逐帧记录搜索用的原始和调整后的返程预测。每一帧先预测，再到下一帧打分，仅统计下一帧仍可观测的同一工人。Brier 分数是概率与实际 0/1 结果之差的平方的均值，越低越好。这项测试衡量单个方向判断的误差，无法直接推出胜率。[复算脚本](live_adaptation_check.py)
