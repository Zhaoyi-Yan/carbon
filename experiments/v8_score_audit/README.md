# Frozen v8 score audit

Run with the arena Python interpreter. The replay inputs come from the archived tree-task and tree-payback manifests. The audit resolves the four exact matches in the published handoff from the frozen team-branches protocol. Each replay must match the archived SHA-256. The tagged strategy is separately checked before instrumentation.

```sh
python experiments/v8_score_audit/audit_scores.py RECENT_REPLAYS OUTPUT
PYTHONHASHSEED=0 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 MKL_NUM_THREADS=1 \
  python experiments/v8_score_audit/replies.py OLD_REPLAYS RECENT_REPLAYS HOLDOUT_OUTPUT
```

The detailed collector records existing values from the candidate loop. It disables the earlier audit's shadow proposal generation. It archives the raw critic (after any original two-view combination), cutoffs, banking target and weight, both economic blends, prior, tail and final EPS decision. The asset components are stored in call order and associated with the tail candidate ordering. The runner reconstructs every leaf and each final score in the original arithmetic order. The raw and postprocessed runner-up actions are both compared with the prior branch archive. The baseline also reproduces five exact real transitions through traced and untraced entry points.

Selected first-step events are computed separately with the local referee. That referee uses the original full board. The strategy sees the acting side's masked view and legal history. Archived natural and historical replies are inserted only in tagged offline re-scoring runs, after candidate generation. When a candidate leaves the comparable finalist set, the log retains the different selection and previous depth outputs.

The reply holdout selects six different layouts, three per seat, by hash from prospective adjacent-planter situations between turns 25 and 149. It avoids earlier experimental turns and all four development layouts. The alternate keeps an enemy planter on its tile when some native v8 candidates send a planter to that tile. It shares all other commands with the sampled reply, skips enemy teammate arrival conflicts and receives the same one-reply search budget. The copied replay command is the evaluation target for first-step planter losses. The report counts false alarms and score changes as well as matches. This is a local diagnosis, with no runtime policy configured to use either historical actions or the additional reply.
