# 胜方行动微调

以线上 yan-v5 的完整 96 通道策略为起点，用胜方实际执行的行动给工人和基地的两个输出层做保守微调。原有骨干、价值网络、教师识别和搜索保持冻结；实际更新四个权重或偏置张量。训练阶段追踪每名工人和基地的动作概率，对当前权重产生的 logit 改变量加上平方惩罚，限制模型过度相信单一批回放。

## 数据与证据

733 个历史缓存都通过 ZIP 完整性和训练字段校验。训练包含 627 局历史比赛和 12 局 yan-v5 线上败局，共 108,397 次工人行动、6,588 次基地决策。历史样本对胜方、前五名和原有局部战术信用使用较高权重。线上样本只使用战胜 yan-v5 的一方。输入使用决策方的部分可见碳量以及当时可见单位信息，胜负只用于训练选样。

此前用于 v5 模型验证的 58 局没有进入本次评估。新增的 48 局历史验证地图中，28 局用于选择输出层更新幅度，另 20 局用于最终测试。线上 17 场可用败局中，最近结束的 5 局单独用于时间外测试。四组之间按开局地图碳量和基地位置指纹检查，地图无重叠。

| 最终测试 | 局数 | 决策数（工人/基地） | 工人负对数似然（v5 → 候选） | 基地负对数似然（v5 → 候选） |
| --- | ---: | ---: | ---: | ---: |
| 历史独立地图 | 20 | 3236 / 182 | 0.51028 → 0.50884 | 0.57700 → 0.56694 |
| 最近线上败局，胜方动作 | 5 | 2923 / 150 | 0.59612 → 0.59477 | 0.65429 → 0.65156 |

表中分数衡量输出层在给定教师风格下对真实动作的预测。线上时间外测试的工人首选动作准确率从 76.50% 变为 76.43%，基地从 71.33% 变为 72.00%。比赛中的搜索、教师推断、现金和胜负需另用完整对局评估。[逐组指标、地图和比赛 ID](learned-validation.json)

## 导出和重训

从已核验 SHA-256 的 yan-v5 源码和 4 KB 权重包，能逐字节重建候选。

```sh
python experiments/v6/learn_export.py yan-v5.py experiments/v6/learned-heads.npz /tmp/learned.py
python experiments/v6/learn_policy.py --data ../v5-data --online ../v6-data --output ../v6-data/learned.py --report experiments/v6/learned-validation.json
```

候选 SHA-256 为 `5eff8928eeb2656d7c55c58e00b3082af8675bade85ea748c7002b93a29c89cc`。部署包大小为 5,793,392 字节。本机使用 Python 3.12、NumPy 1.26.4 和 PyTorch 2.5.1 对该文件做 CPU 前向测试，搜索后端启用，输出有限值。
